```bash
python3 -m http.server 8777
# 然后浏览器开 http://127.0.0.1:8777/demo/巴黎/index.html
```

three.js 全部走各自目录下的本地 `vendor/` 或 `lib/`，没有任何 CDN 引用，断网可跑。

## 许可与剔除口径

`模型/` 下这 56 件按 §00 的口径挑过，以下四类**没有**出现在 `模型/` 里：

| 剔掉的 | 为什么 | 核查结果 |
|---|---|---|
| `citroen-2cv.glb` | 在产商标车型 | ✅ `模型/` 下不存在 |
| `eiffel-tower.glb` | 夜间灯光造型在法国另有著作权主张 | ✅ `模型/` 下不存在 |
| `haussmann-building-lowpoly.glb`、`prop-cafe-shop.glb` | 直接在 Studio 网页点出来的，输入图与提示词都没留，复现不了 | ✅ `模型/` 下不存在 |
| 名画高清复制品裁切、维基照片裁切的发动机与木马 | 扫描件与照片许可证没有逐张核完 | ✅ `模型/` 下不存在 |
| 小王子那一组 19 件 | 角色形象在多国仍有活跃商标与形象权登记；美国公有领域要到 2039 年 | ✅ 全包不存在，连 demo 也撤掉了；只收 22 张图 + 5 个 jsonl |

### demo 这一层为什么不一样

剔除口径只管 `模型/` 那六组素材——那是给人拆出来当素材用的。`demo/` 是完整程序，
要跑就得带自己那份资产，它们的用途是「打开玩一玩，看看这套流水线最后能做成什么样」，不是素材库。
所以三个 demo 各自带着自己的模型：

| demo | 自带的资产 |
|---|---|
| `demo/巴黎/assets/` | 26 件，含 `citroen-2cv.glb`、`eiffel-tower.glb` 等 `模型/` 里没有的 |
| `demo/发动机/assets/models/` | `piston.glb`、`rod.glb` — 输入是维基照片 |
| `demo/星月夜/assets/` | `village.glb`、`cypress.glb` + 5 张名画分层贴图 |

唯一的例外是小王子：它那一组连 demo 一起撤了，理由见上面 demo 一节。

## 校验

`SHA256.txt` 收录包内全部文件的 SHA256（不含 `SHA256.txt` 自身）。核验：

```bash
cd tripo-vibe-coding-资源包 && shasum -a 256 -c SHA256.txt
```
