# 3D Vibe Coding 手册

> 从一句话到能跑的场景：GPT-6 Astra × Tripo 全流程实测

一个不会写代码的人，怎么用 AI 生成 3D 资产，再把它们真正接进一个能跑的项目。
413 页、26 万字、273 张图，六个可玩 demo，所有数字都可核，翻车也没删。

**作者**：花叔（AI Native Coder）· 本书是接 Tripo 商单做视频时的实测记录

## 仓库里有什么

```
book/        手册 HTML 版 + 273 张图
demos/       三个 demo 的源码（GLB 走资源包，代码在这里直接能读）
scripts/     11 个工具脚本：减面极限、批量流水线、GLB 解析与渲图
manifest/    逐件资产清单、分发包索引
```

## 关于模型资产

全部由花叔用自己的 Tripo 积分生成。逐件规格（三角面、顶点、贴图档、体积、生成参数、花了多少积分）见手册附录A。

## 第三方

- **Three.js** — MIT License，随各 demo 附带许可证全文
- **OpenStreetMap** — 巴黎 demo 的路网与河道几何源自 OSM 贡献者，按 ODbL 使用；本应用为艺术化改编，不是导航地图
- 巴黎的程序化城市层复用自花叔自己的「巴黎3D地图-202608」项目，各 demo 的 `ATTRIBUTION.txt` 有完整署名
